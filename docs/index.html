flower

Application de développement personnel : habitudes, journal, routines, sport. Pour PC Windows, tablette et téléphone Android.

Vos données restent chez vous

flower fonctionne entièrement en local, sans compte et sans serveur. Si vous le souhaitez, vous pouvez synchroniser vos appareils par votre propre Google Drive : les données y sont chiffrées sur l'appareil, avec une phrase secrète que vous seul connaissez, avant d'être envoyées.

Dernière version et nouveautés : page des versions. macOS : pas encore disponible.

Installer sur Windows

  1. Ouvrez le fichier téléchargé flower-windows-setup.exe.
  2. Si Windows affiche « Windows a protégé votre ordinateur », cliquez sur Informations complémentaires, puis sur Exécuter quand même. Cet avertissement apparaît pour les logiciels peu diffusés ; flower ne contient ni publicité ni pisteur.
  3. L'installation se fait en quelques secondes. Ensuite, flower se met à jour tout seul.

Fermer la fenêtre garde flower dans la zone de notification, en bas à droite, pour les rappels. Pour le quitter : clic droit sur l'icône, puis « Quitter ». Ce comportement se change dans Réglages.

Installer sur Android

  1. Téléchargez flower-android.apk depuis le téléphone ou la tablette.
  2. Ouvrez le fichier. Si Android demande d'autoriser l'installation depuis cette source (navigateur, gestionnaire de fichiers), acceptez puis revenez en arrière.
  3. Touchez « Installer ». Quand une nouvelle version sort, flower vous la propose ; pour des mises à jour en un geste, ajoutez ce dépôt dans Obtainium.

Pour la synchronisation par Google Drive, l'appareil doit avoir les services Google Play.

Installer sur Linux

  • AppImage (toutes distributions) : rendez le fichier exécutable (chmod +x flower-linux.AppImage, ou Propriétés › Autoriser l'exécution), puis double-cliquez dessus.
  • .deb (Ubuntu, Debian, Mint) : double-cliquez sur le fichier, ou sudo apt install ./flower-linux.deb.
