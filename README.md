# flower — versions à installer

Installeurs de flower, application de développement personnel. Le code est privé ; ce dépôt ne contient que les versions publiées.

- **PC (Windows 10 ou 11)** : [télécharger l’installeur](https://github.com/BianchiTristan/flower-releases/releases/latest/download/flower-windows-setup.exe). Si Windows affiche « Windows a protégé votre ordinateur », cliquez sur **Informations complémentaires** puis **Exécuter quand même**. L’app se met ensuite à jour toute seule.
- **Android (tablette et téléphone)** : [télécharger l’APK](https://github.com/BianchiTristan/flower-releases/releases/latest/download/flower-android.apk) sur l’appareil, ouvrez-le et autorisez l’installation depuis cette source si Android le demande. Ou ajoutez ce dépôt dans [Obtainium](https://github.com/ImranR98/Obtainium) pour recevoir chaque mise à jour.
- **Linux** : [AppImage](https://github.com/BianchiTristan/flower-releases/releases/latest/download/flower-linux.AppImage) pour toutes les distributions (`chmod +x` puis double-clic), ou [.deb](https://github.com/BianchiTristan/flower-releases/releases/latest/download/flower-linux.deb) pour Ubuntu, Debian et Mint (`sudo apt install ./flower-linux.deb`).
- **macOS** : pas encore disponible.

Les autres fichiers des versions (`.sig`, `latest.json`) servent aux mises à jour automatiques : inutile de les télécharger.

Les données restent sur l’appareil : aucune n’est envoyée ici.
