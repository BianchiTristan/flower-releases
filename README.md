# flower — versions à installer

Installeurs de flower, application de développement personnel. Le code est privé ; ce dépôt ne contient que les versions publiées.

- **PC (Windows)** : télécharger `flower_X.Y.Z_x64-setup.exe` dans la [dernière version](../../releases/latest). L’app se met ensuite à jour toute seule.
- **Android (tablette et téléphone)** : télécharger `flower-X.Y.Z-arm64.apk`, ou ajouter ce dépôt dans [Obtainium](https://github.com/ImranR98/Obtainium) pour recevoir chaque mise à jour.

Les données restent sur l’appareil : aucune n’est envoyée ici.
